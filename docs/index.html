Master / Slave

Develop at your desk. Deploy to the rig unchanged.

Keep the sensors on the Raspberry Pi in the rig, and build the automation from your desktop — then ship the same config to the rig with zero changes.

01

Master — your desktop

Run the agent on your PC and drive the rig's real hardware remotely while you write scripts and pipelines. Fast iteration, no walking to the bench.

LAN · rig-01.localor cloud · rig-01
daqcore-agent --mode master --slave rig-01.local
02

Slave — the rig

The Raspberry Pi owns the sensors and exposes them over the network — reachable on the LAN or via the cloud. Same devices, same scripts, same bundles — just a different run mode.

devices.toml→ scripts→ pipelines

Security & compliance

Enterprise-grade, audit-ready by design.

DAQcore is built for regulated labs — where traceability, integrity, and access control are not optional.
